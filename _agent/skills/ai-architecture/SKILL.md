# AI Architecture Skill

This skill manages the dynamic structure of metadata generated by the AI based on the user's focus.

## Content Modes Config
Defined in `src/services/contentModes.ts`. Each mode (e.g., `social_media`, `ecommerce`) defines:
- `fields`: List of metadata fields to generate.
- `applicableTypes`: (Optional) Restricts a field to specific publication types.
- `defaultPrompt`: The base instruction for the AI.

## Dynamic Field Filtering
Implemented through the `getEffectiveFields(config, context)` helper.

### How it works:
1. When generating a prompt (`buildPrompt`), only "effective" fields are included in the instructions.
2. In `chatgptService.ts`, only these effective fields are extracted from the AI's JSON response.
3. In `App.tsx`, only these fields are displayed in the UI and included in the `.txt` export.

### Configuration Example:
```typescript
{ 
  key: 'hashtags', 
  label: 'Hashtags', 
  enabled: true, 
  applicableTypes: ['Feed', 'Carousel'] // Hides for 'Stories' and 'Ads'
}
```

## JSON Schema Enforcement
The system forces the AI to respond in a strict JSON format matching the keys of the effective fields. This prevents parsing errors and ensures consistency across different AI models.
